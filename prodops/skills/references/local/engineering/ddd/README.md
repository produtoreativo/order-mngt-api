# Domain-Driven Design — order-mngt-api

Conceitos e convenções de DDD aplicados neste produto.

## Elementos

- **Entidades:** objetos com identidade própria
- **Value Objects:** objetos sem identidade
- **Aggregates:** agrupamento consistente de entidades
- **Domain Events:** eventos que ocorrem no domínio
- **Repositories:** abstração de persistência
